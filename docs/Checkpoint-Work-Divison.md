# The Swap Shop - Checkpoint Work Division

## Project Overview

The Swap Shop is a campus marketplace designed for students to buy, sell, and swap items with other students.

The project will include a frontend, backend, database, user authentication, listings, transactions, refunds, and item view tracking.

---

## Team Members

### Person 1 - Backend / Database

Responsibilities:

- Build the Java backend
- Set up Spring Boot
- Connect the backend to the database
- Create database tables
- Create API endpoints
- Implement user registration and login
- Implement listing creation and management
- Implement buying and swapping functionality
- Implement transaction handling
- Implement refund processing
- Implement item view counting
- Connect the backend to the frontend
- Test backend functionality
