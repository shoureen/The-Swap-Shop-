# The Swap Shop - Technology Stack

## Frontend

### React

React will be used to build the user interface for The Swap Shop.

The frontend will include:

- Homepage
- Marketplace
- Listing details
- Listing creation
- Login
- Registration
- User profile
- Transactions
- Refund requests

### Vite

Vite is used to create and run the React frontend during development.

### React Router

React Router is used to navigate between pages.

Current routes include:

- `/`
- `/marketplace`
- `/listing/:id`

### CSS

CSS is used to style the website and create the visual design.

---

# Backend

## Java

Java will be used to build the backend of The Swap Shop.

## Spring Boot

Spring Boot will be used to create the backend REST API.

The backend will handle:

- Users
- Authentication
- Listings
- Transactions
- Swaps
- Refunds
- Item views

---

# Database

## PostgreSQL

PostgreSQL will be used to store application data.

Potential database tables include:

- Users
- Listings
- Categories
- Transactions
- Swaps
- Refunds
- Listing Views
